# 串口协议（主机 ↔ ESP32-S3 KVM 板）

串口：USB Serial/JTAG（CDC），**115200 8N1**。
所有帧以 `0xAA` 开头，第二个字节为帧类型。

---

## 主机 → 板

### 键盘报告 `AA 01`

```
AA 01 <mod> 00 <k1> <k2> <k3> <k4> <k5>
```

| 字段 | 说明 |
|---|---|
| mod | HID 修饰键位（bit0=LCtrl, bit1=LShift, bit2=LAlt, bit3=LWin, bit4=RCtrl...）|
| 0x00 | 保留（HID boot 协议固定字节）|
| k1..k5 | 按下的 HID Usage（最多 6 键同时，第 6 个为 0）|

每按/松一个键发一次完整报告（状态同步），不是增量。

### 鼠标报告 `AA 02`

```
AA 02 <buttons> <dx> <dy>
```

| 字段 | 说明 |
|---|---|
| buttons | bit0=左键, bit1=右键, bit2=中键 |
| dx / dy | 相对位移（有符号 8 位，-128..127）|

### 切换目标 `AA 05`

```
AA 05 <slot>
```

`slot` = 0 或 1（多主机时选择连哪台）。板子回 `AA 06`。

### 远程关机 `AA 07 01`

```
AA 07 01
```

板子通过 GATT `0xFF02` 通知目标端，目标端执行关机后回 ACK（`AA 03 01 0x10`）。

### 状态上报 `AA 04`

```
AA 04 <state>
```

`state`: 0=本地(绿), 1=slot0(蓝), 2=slot1(紫)，驱动板载 LED。

---

## 板 → 主机

### 切换 ACK `AA 06`

```
AA 06 <slot> <conn_count>
```

`conn_count` = 当前 BLE 连接数（用于主程序循环切换）。

### 命令 ACK `AA 03`

```
AA 03 01 <val>
```

| val | 含义 |
|---|---|
| 0x10 | OK（目标端已执行）|
| 其他 <0x10 | 历史 BOOT 键信号（已废弃，改用 AA 08 区分）|

> 注意：`AA 03 01 01` 曾是 BOOT 键切换信号，现已移除（改用 AA 08 发 LED 状态），
> 避免键盘 LED 变化被误判成切换。

### LED 状态 `AA 08`

```
AA 08 <report_id> <led_val>
```

仅供日志/调试，主机可忽略。

---

## GATT 服务（0xFF00）

| 特征 | 属性 | 用途 |
|---|---|---|
| 0xFF01 | Write | 目标端 → 板（ACK 回执）|
| 0xFF02 | Read | 板 → 目标端（命令，目标端轮询读取）|

**为什么用 Read 而不是 Notify**：Notify 需要 CCCD，而 `CONFIG_BT_NIMBLE_MAX_CCCDS`
默认只有 8 个，HID 的 Report 特征已占满，新增 CCCD 会导致 HID 特征注册失败、
键鼠全部失效。用 Read + 轮询绕开这个限制。

---

## 帧解析注意事项

板子串口可能收到不完整帧（USB 缓冲/分包），主机端解析时应：

1. 累积字节到缓冲区
2. 查找 `AA 01` / `AA 02` / `AA 03` / `AA 06` 等帧头
3. 按帧长度截取，剩余字节保留
4. 找不到帧头时丢弃到只剩 1 字节（防止缓冲区无限增长）
